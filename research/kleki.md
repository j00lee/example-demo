## Snapshot

Kleki is the closest functional comparison for a lightweight browser painting experience. Its official page describes natural brushes, layers, editing, import, save/upload, filters, and pressure sensitivity, and identifies the project as open source and free.

## Relevant capabilities

- Multiple natural brushes
- Layers and image editing
- Filters
- Import and upload workflows
- Save/export workflows
- Pressure sensitivity
- Multilingual UI and light/dark themes

## Extensibility signal

Kleki demonstrates a broad feature set built around a browser painting surface rather than a collaborative whiteboard. Its open-source positioning is useful for studying how a canvas can grow from a basic brush into a small editor.

## Competitive lesson

Brush feel, touch support, and predictable image persistence are meaningful differentiators for a drawing app. The feature list can expand quickly, so a narrow first release should make the brush interaction feel excellent before adding layers or effects.

## Opportunity for this app

Offer a calmer, more focused alternative: one pencil, one eraser, a readable size control, and a clean canvas. The next high-value additions would be undo/redo, export, and pressure-aware input before filters or complex editing.
