# Competitor Research Follow-up Plan

## Next product checks

1. Compare first-draw time across this app, Kleki, Excalidraw, and Sketchpad.
2. Test pencil stroke smoothness on mouse, trackpad, and touch input.
3. Add undo/redo and PNG export as the first likely post-research features.
4. Keep drawing actions represented as tool-driven stroke events so collaboration can be explored later without changing the UI contract.
5. Revisit tldraw's tool and shape extension patterns if the app expands beyond freehand marks.

## Decision gate

Only add another visible tool when it solves a repeated user need demonstrated by testing. Preserve the current two-tool simplicity as the default experience.
